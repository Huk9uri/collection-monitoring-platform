# 인증·모니터링 정책 제어 DB 구현 계획

## 이번 단계

인수인계 구현 순서의 1단계인 SQL 스키마 계약 테스트와 100 생성·105 읽기 전용
검증 스크립트를 작성한다. 실제 DB 적용과 계정 생성은 포함하지 않는다.
후속 단계는 제어 DB 연결과 최소 권한 repository이다.

## 작업 경계

`codex/monitoring-control-schema` 브랜치에서 신규 파일만 추가한다. 기존
스마트플레이스·네이버 영업시간 미커밋 변경은 보존하고 함께 커밋하지 않는다.
이 브랜치는 기존 작업 트리를 공유하므로 기존 변경도 계속 표시된다.

## 구현 및 검증

1. 일곱 테이블, 제약조건, 조회 인덱스, SELECT-only 검증 계약을 테스트로 작성한다.
2. 테스트 실패를 확인하고 트랜잭션 기반 SQL Server 생성 스크립트를 작성한다.
3. 메타데이터와 실행 계정의 유효 권한을 조회하는 검증 스크립트를 작성한다.
4. 계약 테스트를 실행하고 배포 전 DBA 확인 항목을 한국어로 기록한다.

운영 DB와 스키마는 미확정이다. 제공 스크립트는 `dbo` 템플릿이며 실제 대상과
스키마를 DBA가 확인한 뒤 사용한다. 런타임에서는 DDL을 실행하지 않는다.
