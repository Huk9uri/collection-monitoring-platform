# 네이버 영업시간 조회 오류 보완

## 원인

연결 및 상태 집계는 성공했지만 실행 데이터 대조 단계에서 실패했다.
실제 최신 2건의 SQL 시작·완료 시각은 밀리초까지만 남아 있고 JSON은 마이크로초를
보존했다. 두 컬럼은 datetime2(6)이므로 스키마 정밀도 부족으로 단정할 수 없으며,
저장 경로의 절삭 결과와 일치하는 것을 확인했다.

## 변경

SQL 시각이 JSON 원본과 정확히 같거나, JSON 원본을 밀리초 단위로 절삭한 값과
정확히 같은 경우만 허용한다. 임의 시간 오차 허용 범위를 추가하지 않는다.
NULL 불일치, 상태·식별자 불일치, 실제 시각 차이는 계속 거부한다.
반환 데이터는 JSON 원본 시각을 유지하며 DB 데이터는 변경하지 않았다.

## 검증

- 회귀 테스트에서 절삭 차이로 인한 실패를 먼저 재현했다.
- 마이크로초 보존, 정확히 일치하는 시각, 실제 불일치와 NULL 거부를 검증했다.
- 전체 API 테스트 275개 통과.
- 실제 DB SELECT-only 검증: 최신 실행·신선도 2건·목록 2건·카드 조회 성공.
- 실행 중인 API가 reload 모드가 아니라면 서버 재시작 후 화면 새로고침이 필요하다.
