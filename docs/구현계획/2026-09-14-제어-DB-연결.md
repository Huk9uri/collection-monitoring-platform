# 제어 DB 연결 구현 기록

사용자가 DDL 실행 완료를 전달했다. 실제 DB 적용 결과와 런타임 권한은 이 작업에서
직접 검증하지 않았으며, 105 검증 스크립트 결과는 별도로 확인해야 한다.

## 구현 범위

- `MONITORING_CONTROL_CONNECTION_STRING`을 SecretStr 설정으로 추가했다.
- 제어 DB 팩토리는 전용 연결이 없을 때 실패하며 수집 DB로 대체하지 않는다.
- 연결은 autocommit=False를 사용하고 성공 시 커밋, 실패 시 롤백 후 닫는다.
- 고정 SQL과 파라미터 바인딩을 사용하는 사용자 조회 repository를 추가했다.
- 비밀번호 해시는 사용자 객체 repr에서 제외하고 DB 예외는 정제한다.

신규 연결 경계와 repository는 아직 API에 연결하지 않았다. 기존 익명 viewer
동작은 남아 있으므로 이번 변경만으로 인터넷 공개용 인증이 완료되지 않는다.
다음 구현은 Argon2id·토큰 보안 함수, 세션 repository, 로그인 API 순서다.
정책 변경과 감사 트랜잭션 repository는 해당 정책 구현 단계에서 추가한다.

## 검증

기존 가상환경에 pytest가 없어 unittest 기반 신규 테스트를 작성했다.
실제 제어 DB에 DML을 수행하지 않고 가짜 연결로 트랜잭션 수명과 오류·조회 계약을
검증한다. 전체 API 회귀 검증은 프로젝트 테스트 의존성 복구 후 수행해야 한다.
